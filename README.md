# 鳥取旅帖

鳥取県を歩きながら、名所・史跡・文学ゆかりの地・人物ゆかりの地・飲食店などを見つけ、訪問やすれ違いを記録する軽量Webアプリ。8bitのネコが目印。

## PoC（2026-10-24）

- **近傍検索**: OpenPOI API `GET /v1/search` をブラウザから呼び出す。原則半径3.5km、最大200件。
- **文化スポット補完**: 鳥取市オープンデータで位置を確認できる尾崎放哉の句碑2件。OpenPOI の観光名所網羅性は保証されない。
- **種類**: 史跡／文学／人物／ごはん／夜／すべて／旅帖。OpenPOI のカテゴリから推定するため誤分類・欠落がある。
- **記録**: 「見つけた」「ニアミス」「すれ違った」「訪れた」。訪問はユーザーが手動登録する。
- **自動記録**: 利用者が「すれ違い ON」を押した場合だけ、アプリが前面で開かれている間にGPSを利用。GPS精度70m以下かつ2測位以上の場合、距離110m以内をすれ違い、500m以内をニアミスとして扱う。背景追跡はしない。夜の施設は自動記録しない。
- **共有**: ブラウザ上で旅帖PNGを描画、iOS共有またはダウンロード。印刷→PDF、JSONバックアップ／復元も用意。
- **試用**: 「鳥取駅で試す」は模擬位置。そこで行った記録にはおためしラベルが付く。GPSによる接近記録は行わない。

## 起動方法

`index.html` をHTTPSの静的サイトから開く（GitHub Pagesなど）。APIキーやビルド、サーバーは不要。現在地取得にはHTTPSと端末の位置情報許可が必要。

**PoCのソースがGitHubへ保存されたこととWeb公開・iPhone実機確認は別です。** 現在の機能説明は実装したコードの仕様であり、未検証の実機動作を保証しません。

## データとプライバシー

旅の記録は端末ブラウザの localStorage に保存。訪問したPOI名・POI座標・日時・最短距離・データ出所・ライセンス・記録種別を保持するが、GPSの生座標や移動軌跡は永続保存しない。**検索時には現在地の緯度・経度がOpenPOI APIへ送信される。** バックアップと共有画像は利用者の操作時のみ生成。シークレットブラウザ・ストレージ削除では記録が消える可能性があるため、JSONバックアップを推奨。

PoCの自動判定はGPSと施設座標の誤差を含み、「来店」「入館」「参拝」した証拠ではありません。施設情報は閉店・誤位置があり得ます。夜の施設は明示的なタブ操作でのみ検索。利用者の行動を第三者へ自動送信する機能はありません。

## 開発方針

初期PoCではブラウザの単発検索と最小限の記録を優先。ログイン、バックエンド、地図タイル、常時バックグラウンドGPS、訪問自動確定は追加しない。コード、GitHub保存、Web公開、実機検証を別々に記録する。
