# APP-025｜文学の現地スポット増補 第4次（2026-10-25）

## 重点方針
作品の紹介文は名称・作者・公開資料の関係を短く示す程度にとどめ、旅行者が訪ねられる文学碑・歌碑・句碑・散歩道・関連施設の**発見と地図表示**を最優先する。根拠のない地点のGPS座標を作らない。

## 成果
- `literary-sites-04.js` に **17件**（鳥取市・東部10／米子・西部4／倉吉・中部3）の独立した地図候補を追加。
- 既存の書誌58作品や文学スポットの既存IDはそのまま。場所の重複登録は行わない。
- 住所カタログを **109→126件** に更新。新17件には公開資料の住所・町域のみを収録。**新17件の施設固有の座標はまだ未取得**。
- 未取得位置はアプリから地理院の住所APIを呼び、返った座標を**住所の代表位置**として地図表示・端末キャッシュする。新17件の問い合わせを優先し、リクエストを直列化する。
- 「ふるさとの歌の道」「鳥取砂丘西側文人歌碑群」は**広域の集合地点**であり、個別碑を示すピンでもGPSすれ違い自動判定地点でもない。
- 単独の歌碑は登録住所の代表位置として400mの近隣すれ違い候補になるが、個別の碑の実測位置が確定したわけではない。
- 著作権未確認の歌詞・詩句の長い引用、作家の非公開住宅情報を含めない。

## 出典・精度
個別レコードの `url` / `attributions` / `evidenceLevel` に出所を保存。
- **公式・公的資料により存在が確認できる8件**：鳥取市観光サイト「ふるさと音楽碑」「ふるさとの歌の道」「鳥取砂丘西側の歌碑群」、鳥取県「春が来た（天満山公園）」「万葉の郷（粟嶋神社）」「万葉歌碑（山上憶良）」、米子市報2012年5月号の生田春月詩碑2件。
- **現地訪問者の歌碑写真・住所資料を主な根拠とする9件**：袋川・醇風小学校前・智頭橋・三朝橋・かじか橋・鹿野町公園・修立小学校前・わらべ夢ひろば・福塚公園の歌碑。出所は `https://monument.sakura.ne.jp/31tottoriken.html` と各碑の詳細ページ。掲示位置の現況、移設、施設への立ち入り条件は実機・現地未確認。
- 上淀白鳳の丘展示館の公式住所： `https://www.yonagobunka.net/hakuhounooka/exhibition/info/`。生田春月碑が同館前にあるという情報は米子市報 `https://www.city.yonago.lg.jp/secure/15136/201205.pdf`。
- 山上憶良歌碑は倉吉市立図書館 `https://www.city.kurayoshi.lg.jp/5683.htm` および鳥取県 `https://www.pref.tottori.lg.jp/287308.htm` を参照。伯耆国分寺跡の公園所在地「倉吉市国府」は**地域表示**。
