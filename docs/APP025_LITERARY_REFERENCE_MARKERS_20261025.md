# APP-025｜文学碑が一覧のみで地図に出ない問題（2026-10-25）

## 実機の症状
Safariで鳥取砂丘周辺の「文学」を選んでもピンが見つからず、一覧・施設詳細には高浜虚子句碑などが表示される。以前のデプロイ漏れはPR #32・#33で修正済みだが、それとは別に地図位置の解決で問題があった。

## 原因
旧 `literary-batch-01.js` は文学関連38件のうち36件に `referenceArea`（地域の参考座標）を保持していた。一方 `withCatalog` は `lat,lng` または住所APIのキャッシュがある場合しか座標を渡さず、`drawMarkers` は座標がnullの地点をスキップした。住所の表記が「鳥取市浜坂・鳥取砂丘西側」などのため、GSI検索だけでは個々の碑の地図表示を保証できない。

## 今回の最小修正
- 元からある `referenceArea.lat/lng` を、住所APIの取得がない場合の **地図表示専用の参考点** として使用する。ネットワーク接続に依存せずピンが出る。
- 同じ座標を持つ「文学の小径」「砂丘西側の5碑」は一つの冊数付きピンにまとめる。タップすると個別の碑名を選択でき、詳細画面の「地図で見る」で参考地点に移動できる。
- 参考位置は `概略位置`・`自動すれ違い対象外` と明示する。GPS自動記録には利用せず、旅帖の既存ID・日時・手動操作は保持する。
- 以前追加した58文学作品→15地域の**本ピン**とは別のマーカー。作品の集約ピンと個別の文学碑群のピンを混同しない。
- 新たな座標は発明・補正しない。既存 `referenceArea` をそのまま使用し、将来個別碑の測位根拠が得られたら置き換える。
- PagesのJS自動梱包・不足チェック、Leaflet地理院タイル、住所台帳126件は維持。

## 確認（模擬実行）
- 鳥取砂丘西側の5碑（有島武郎・与謝野晶子・枝野登代秋・高浜虚子・森川暁水）は全て代表点 (35.544, 134.22) を取得、GPS自動判定は5/5で無効。
- 砂丘付近の地図範囲で5碑を1つの「5」ピンに集約。タップで個別5件の詳細ボタンを生成。
- 独立した58作品の地図ピンは東部6件、鳥取砂丘は20作品として表示される構造を確認。
- iPhone Safariでの修正後ピン表示・GitHub Pagesの最新実配信は **未検収**。

## 次の検収
鳥取砂丘の地図を表示して「文学」フィルタを選び、5碑まとめピンと20作品の本ピンを確認。高浜虚子句碑の詳細から「地図で見る」を押して参考座標へ移動するか、個別碑の正確位置と混同しない表示かを確認。
