# APP-025｜旅帖進捗フィルターとアイコン原画（2026-10-25）

## 旅帖「みつけた・すれ違い・訪れた」の操作

- 3つの集計枠をボタンに変更。選択中は黄色、もう一度押すと解除。
- 既存ジャンル絞り込みとAND条件で連動。
- 一地点の現在の到達段階は **訪れた > すれ違い > みつけた**。複数の日時を持っていても3つの枠には重複計上しない。
- タップしても `localStorage` の訪問・発見・すれ違い記録を変更しない。全件JSONバックアップは表示中のフィルターと無関係に全件。画像/PDF（印刷）の出力は現在の絞り込みに連動。
