# APP-025｜画像アイコン台帳（2026-10-25）

## 番号体系
合計65件。元からある30画像（12原画アトラス＋18 POIアトラス）と、追加生成シートから切り出した35画像を、`assets/ICON_REGISTRY.json` に連番で登録。番号は今後変更しない。

- IC-001〜012：既存12画像（従来の地図・詳細アイコン）
- IC-013〜030：既存POI 18画像
- IC-031〜034：雑貨店、工芸店、土産物店、カフェ。生成画像から切り出し、軽量WebPを `assets/extended-icons.css` に画像データとして埋め込み、地図ピン・施設一覧・詳細画面へ実装
- IC-035〜065：追加のイラスト候補。原画シートから切り出した個別PNGは `APP025_35_pixel_icons.zip` に収録。**このZIPは会話で提供する成果物でありGitHubには未保存**。現段階ではアプリで使っていない

## ジャンル
カフェ（`cafe`）と宿泊（`lodging`）を新設。カフェは飲食（`food`）から独立。買物（`shop`）では雑貨・工芸・土産物のピンを使い分ける。カテゴリと画像アイコンは独立して管理する。

## 地図上の範囲再検索
Leaflet地図の内側に小型フローティングボタンを配置。現在の移動量判定を再利用し、地図を移動・ズームした後に出て、再検索後は消える。API・地図タイルの読み込み機構は変更しない。

## 品質・継続
GitHubに公開した画像は埋込WebP 4種類のみ。シートからの他の31切り出し画像は候補であり、採用とGitHub保存は後工程。素材の原画へのアクセスが切れた場合は会話成果ZIPを利用。旅帖とGPS記録のキーは変更しない。
