# APP-025｜寺社・史跡・名所の公式資料増補（2026-10-25）

## 分類方針

- **寺社**：現在の寺院・神社・社殿・堂宇。宗教上の信仰施設は重要文化財・史跡に指定されていても一次分類は寺社とする。
- **史跡**：城跡、古墳、廃寺跡、旧国府、歴史上の遺構、墓所など。**上淀廃寺跡や栃本廃寺跡は「寺社」ではなく「史跡」**。
- **名所**：県公式「とっとり旅」に掲載された景勝地、自然・街並み、観光施設を優先。地形が史跡や名勝に指定されていても観光対象としては名所に置く。
- **偉人**：人物の業績・関係が明確な記念館・生家等。例：名和神社は「寺社」主分類にして名和長年への関連タグを残し、人物検索にも対応する。
- 既存の「文学」「飲食」は維持。**「風俗」は発見タブ・カテゴリ・成人向け確認画面から廃止**。既存の端末保存記録は削除せずバックアップ可能、「施設」として表示する。

上記の32件は**場所の存在と所在市町村・地域の根拠がある参考地点**であり、個別GPS座標の精査は未完了。すべて `lat:null`、`lng:null`、`verified:false` で登録。地図ピンや自動すれ違いを推測で出さない。住所欄は公式情報の所在地概要を含み、入口の位置保証ではない。関連人物があるものは `relatedTypes:['people']` を設定した。

旧 `GUIDES` の白兎神社は史跡→寺社、倉吉白壁土蔵群は史跡→名所と主分類を修正。旧旅帖の寺社誤分類は記録のID・訪問/発見時刻を保持したまま表示時に補正する。

## 現在地の位置付け

- 初期地図の鳥取市中心は**GPSではない**。iPhoneが鳥取県外でGPSを取得した場合、「鳥取県外」と表示し、鳥取県内の架空GPSマーカーを作らない。
- 正常なGPS位置が県内で得られたときにだけ現在地のひし形と認証表示を使う。
- 既にiPhone実機合格済みのLeaflet標準 `L.tileLayer()`、地理院 `pale`、自サイト配信Leaflet CSSは変更しない。

## 最小受入と後続

1. 寺社/史跡/名所の排他的主分類、風俗タブ削除、32件ユニークな情報源。
2. 公式地点は地域リストと名称検索で参照可能、個別位置未確認のGPSピンはゼロ。
3. 既存旅帖履歴・JSONバックアップを保全、旧風俗ラベルは画面上「施設」とする。
4. 県外GPSでは鳥取中心に「現在地」を出さない。
5. 公開成功後のiPhoneの7タブと寺社検索は利用者実機で確認（長期・大量テスト禁止）。

後続は、公開地図上で個別座標を確実に照合できた寺社・史跡を1件ずつ `verified:true` に昇格する。
