# APP-025｜文学コンテンツ第3次増補（2026-10-25）

## 目的と成果
県内の文学碑・人物ゆかりの施設だけでなく、「鳥取が登場する作品」を旅行の文脈で閲覧できるようにする。

- 第3次 **文学作品58点**：`literary-works-03.js` の `TOTTORI_LITERARY_WORKS_03`
  - 鳥取市・砂丘・東部28、米子・大山・日南14、倉吉・中部10、境港6
- 第3次 **文学ゆかりの訪問可能な公共地点3点**：同ファイルの `TOTTORI_LITERARY_PLACES_03`
- 固定所在地台帳：旧106件 + 新3件 = 109件（`location-catalog.js`）。
- 従来の文学・人物46件および他の固定施設IDを変更しない。

## 作品と地点の関係
- 作品は **書誌情報** であり、店舗・記念碑・観光地のようなGPS位置を持つPOIではない。
- `targetId` は旅行者が訪問できる既存の代表地点・関連地への**案内リンク**。登場する作品の正確な出来事の場所、作品の主舞台、作家の滞在場所を保証しない。
- 作品を開くだけで、新たな旅帖エントリやGPSすれ違い記録を生成しない。関連する地点を開いた場合は従来どおりの「みつけた」挙動。
- 「文学」のジャンル選択時に、エリアごとに作品名・著者・登場地を最大8件表示し、さらに表示操作で全件閲覧可。
- 検索語があるときは、名称・著者・登場地の文字列で全エリアを検索できる。作品の資料リンクから県立図書館の一覧を開ける。
- 書誌作品の冊数を通常の地点数や旅帖の件数へ加算しない。

## 主な一次・公的資料
1. [鳥取県立図書館「鳥取県が登場する文学作品」](https://www.library.pref.tottori.jp/information/cat4/5iQsDPU6NDdtBkZsqpgNd082ZfjwBK7prgNOPPoU.html)（2026年5月12日更新）：作品名・著者名・登場地の根拠。**掲載作品の主舞台とは限らず、地名だけが登場する作品もある**ことに留意。
2. [県立図書館「生田春月」](https://www.library.pref.tottori.jp/information/cat4/cat18/post-10.html)：『相寄る魂』と米子の結びつき。
3. [日野町「生田長江の碑」](https://www.town.hino.tottori.jp/1285.htm)：根雨駅近く延暦寺境内。
4. [日南町・生山駅／上石見駅開業100周年](https://nichinan-cho.jp/100th-station/kamiiwami/)：池田亀鑑文学碑が旧石見東小学校に建立された記録。
5. [大山自然歴史館「大山の文学碑めぐり」](https://daisen-museum.jp/schedule/event/69/)：館の所在地、西伯郡大山町大山43と文学碑散策イベント。館は文学碑そのものとは区別。

## 位置・閲覧上の注意
- 新3件は既存座標のない参照地点として追加。住所や地区名のGSI代表点取得は既存の自動住所解決機能に任せる。
- 町丁目の代表点を施設入口の精密座標と表記しない。GSI接続が失敗しても偽のGPS点を作らない。
- 個人の非公開住所、著作物本文の長文引用、書影等の権利未確認コンテンツは掲載しない。

## 既存機能の維持
- 地理院淡色タイル + Leaflet、カフェ/飲食の複合絞り込み、アイコン台帳、住所以外のGPS判定に変更なし。
- 旅帖データのキー `tottori-trip-v1` と復元JSONの互換性を維持。
- コード保存・main統合・Pages配信・Safari実機確認は別のマイルストーンとする。
