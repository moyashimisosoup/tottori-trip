みつけた：気になる場所を開くと旅帖に残ります。

すれ違った：近くを通ったら記録。自動記録は「すれ違い ON」時のみ、画面を開いている間だけ動きます。

訪れた：実際に行ったら自分で記録。

距離は目安。GPS精度や登録地点のずれがあります。表示しただけでは訪問とはなりません。

近くの施設を探す際、検索中心の座標をOpenPOI APIに送信します。GPSの移動履歴は保存しません。旅帖はこの端末に保存され、消去すると失われます。バックアップをおすすめします。

施設データ：OpenPOI API 出典・ライセンス。文化スポットの補助情報：とっとり旅、鳥取県文学探訪。
